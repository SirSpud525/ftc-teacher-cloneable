This repo contains everything needed to start with the FTC Teacher app. You should be able to clone this, open it in Android Studio, and get started as soon as the project is done importing. It is best to also version control the project, which can be done by forking this repo and cloning the fork. Other practice functions for Unit 1-4 are located at https://github.com/SirSpud525/ftc-practice-code and are recommended be used alongside this during or at the end of their units, which is particularly helpful for Unit 1 since this repo picks up starting in Unit 2.



For contributors:



The SDK version will need to be brought up to date each season. This can be accomplished by cloning the project, adding a remote which links to the FTCRobotController SDK repo, then pulling and merging changes from that remote into the current project.
